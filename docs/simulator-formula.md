# 計算式と結果の読み方

Simulatorの「計算式・用語」を開くと、Player→MobとMob→Playerの近接・投射物・魔法を確認できます。説明は既定で閉じています。展開時も画面全体をスクロールして計算、詳細、比較へ進めます。

「最後に計算した要求との対応」は実行番号・命中ID・経路・その要求に保存した矢やバニラ会心等の条件を表示します。1回の結果ではCoreが返した防御前値、式計算結果、通常会心と、算出/純HP減少/追加HP(OH)吸収/実適用を対応付けます。結果詳細と同じ50行のページに連動します。入力や装備を編集しても、この説明は再計算まで変わりません。発射時の記録は特殊効果の判定用であり、式で使う能力全体を発射時へ戻しません。

式計算結果には通常会心・防御等を含み、その後の命中補正・拒否を含みません。算出と実適用は残HP・OH等により異なります。未命中や死亡後など式評価記録のない行は「式結果なし」です。厳密期待値は各枝の確率と結果の積の合計で、平均能力を式へ代入しません。途中枝の処理記録や平均状態、単一の会心判定を補いません。取消・上限超過・対応外には数値結果を付けません。

## 正本と照合

説明の正本は固定CombatCore `0c5b1a4cd431d3394ce01e9f118e1a7d7f4920ab`の`PlayerToMobDamageCalculator`、`MobToPlayerDamageCalculator`と既存`DamageFormulaBaselineTest`です。Managerに式の計算処理を追加していません。実参照artifactの完全座標・JARのSHA-256・Core/DataModelのsource commitは`recordCombatCoreDependency`で`build/reports/combat-core-dependencies.properties`へ記録します。依存を更新するときはこの記録と固定ソースを照合し、画面説明と以下の例も確認します。

独立した手計算例（すべて命中時の追加補正前）は次のとおりです。

| 条件 | 手計算 | Core baseline |
| --- | --- | --- |
| 近接: 物理95、筋力20、対象防御200・防御貫通500→実効防御100、非会心 | (5+95)×1.2×100/200=60 | 60 |
| 同条件、会心ダメージ50%で会心 | 120×1.5×100/200=90 | 90 |
| 同条件、BREAK中 | 120×100/100×1.2=144 | 144 |
| 同条件、大剣バニラ会心 | 60×1.2=72 | 72 |
| 魔法: 魔法80、知力50、対象防御200・防御貫通500→実効防御100、非会心 | 80×1.5×100/200=60 | 60 |
| 投射物: 防御前120、防御200、貫徹矢rank10 | 120×100/(100+200×0.85)=44.44444444444444 | 同値 |
| 投射物: 防御前120、防御200、距離4 | 120×100/300×(1-0.11)=35.6 | 35.6 |
| Mob近接攻撃力90、Player防御100 | 90×100/200=45 | 45 |
| Mob投射物攻撃力180、Player防御100 | 180×100/200=90 | 90 |
| Mob魔法攻撃力150、Player防御100 | 150×100/200=75 | 75 |

近接・魔法では通常防御貫通1ptにつき0.001、投射物では貫徹矢rankにつき0.015を使います。投射物へ通常防御貫通を足しません。主手が攻撃種に適合しなければ、近接・投射物は主手寄与だけを除外します。魔法は主手を除外しません。この画面の魔法入力にはCoreの固定加算・会心無効・貫通無視の上書きはありません。

Player近接・魔法とMob3経路では防御分母が非有限または0以下のとき軽減しません。Player投射物には同じ分母除外処理がないため、一つの一般式へまとめていません。Mobの攻撃手段別値は未指定時だけ基礎攻撃力を使い、非有限・0以下の攻撃力は式結果0です。

## 検証範囲

`SimulatorFormulaViewTest`は実FXMLの折畳み、6経路、要求の固定、未完了・期待値の表示、小画面スクロールを確認します。既存の計算受入、複数命中、結果詳細、比較テストで同tick順序、OH、拒否、死亡後、厳密期待値を確認します。実行OSと結果は作業記録に残し、未実施OSや人間による実操作を成功扱いにしません。
