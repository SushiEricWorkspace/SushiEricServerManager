# ローカル一覧と送信予約

接続中の左一覧はオフラインと共用のローカル作業コピー、右一覧は現在の接続先の作業コピーと宛先ディレクトリです。同じ機能のView内で保存元別に編集中・履歴・参照を保持し、Sessionや接続先を切り替えません。編集用の従来一覧は保存元メニューの「編集用一覧を表示」で再表示でき、型固有の改名・移動・削除を利用できます。

ローカルの複数ファイルやフォルダーを宛先ディレクトリへdropすると送信予約へ追加します。「選択を宛先へ予約」も同じ予約処理を使います。選択フォルダーからの相対階層を維持し、重複選択を正規化します。編集中内容は正規の保存確認を通し、取消や保存失敗では追加しません。型付き文書の保存済みrawが残る場合は予約できません。予約や再割当てだけでは接続先へ書き込みません。

同じ接続先の複数ディレクトリへ予約でき、下部一覧で再割当て・削除・順序変更を行えます。横スクロールは順序変更とは別です。コピーごとのItem/Ore内部IDと選択集合内の参照対応は予約に固定します。既存宛先の更新は現在の内部IDを維持し、予約後に宛先が生成・差し替えされた場合は再割当てを求めます。Shopの実反映はD3 capability未接続のため保留し、旧YAMLへは反映しません。

「予約を確認して一括実行」は各予約の差分を確認してから、保存済み本文と予約の変換対応を固定した実行台帳へ結び付けます。元のローカル文書や別保存元を書き換えず、Item参照を先に確認・反映します。通常送信とコピーの成功比較元は混同せず、コピーの変換識別と変換済み本文を台帳へ保持します。送信対象文書だけを凍結し、非対象の保存元切替は既存I/Oqueueの正規退避完了後に行います。IME未確定中や保存中の受付拒否、読込失敗、画面終了では文書表示要求を失敗通知して解放します。

予約は保存元別の `upload-plans` 配下へCAS・原子的置換で保存します。形式はversion 1で、未対応・破損した形式は原本を保持して拒否します。渡されたリストやID対応表は境界で複製し、保存済み予約を可変参照から変更させません。再起動で予約を復元しても自動送信しません。

実行台帳に結び付いた予約は、同じ接続先のI/Oqueue上で元要求の停止を確認してからだけ削除できます。確定失敗や取消の台帳も残します。WRITING/UNKNOWNや未確定の要求を削除・再割当てして別要求へ飛び越しません。結果不明は一覧の「同じ要求を読戻し」で本人が選択した永続要求へ照合し、自動再送しません。台帳を再読込できない場合も対象の保全凍結を維持します。

SFTPの最新読取と書込は遠隔側で原子的ではありません。論理保存元は実world同一性の証明ではなく、外部サーバーや在庫DBの比較書込・排他を追加する機能ではありません。予約順序は参照依存の実行順を上書きしません。物理Dragboard/trackpadとFXイベント検証は区別し、専用fixtureの再起動とhelper明示openを通常workspaceの自動layout復元の実証として扱いません。
