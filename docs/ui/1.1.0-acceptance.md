## 正式配布の準備と残作業

正式依存候補は`io.github.sushiericworkspace:sushieric-datamodel:1.1.0`と`io.github.sushiericworkspace:sushieric-combat-core:1.1.0`です。DataModelの公開採掘計算API追加を新しい正式版へ含めます。Coreのソースは固定でも、`publishRelease`へ渡すDataModel版がPOMの`api`依存へ反映されるためCoreも新しい正式版とし、既存1.0.0を異なる内容で再発行しません。

開発artifactのhashは正式配布artifactのhashではありません。正式ビルドはmain統合後の固定commitから既存Build InstallerをWindows/macOS各1回実行し、両依存の版・完全source commit・CoreのDataModel座標、CI検査成功、run/headSha、取得可能なruntime JAR・exe/dmgのhashを照合します。既存workflowはPOMをuploadしないため正式POM hashは未取得として扱います。dev POM hashを正式POMの実測へ流用しません。

main統合・CI1回・Releaseはユーザー依頼済みです。実行と成功は別に記録し、[リリースガイド](../update/release-guide.md)に沿って進めます。Installer実行環境・Mac専用作業pathの確認を行い、インストール/起動・正常終了/再起動・更新と、tag `v1.1.0`・両asset・latest公開の整合が揃うまで正式Release完了とはしません。
