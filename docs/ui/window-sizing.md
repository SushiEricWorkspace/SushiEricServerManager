# ウィンドウのサイズ制御

通常Managerとdevelopmentの画面は、`Utility.createScene`で作ったSceneをStageへ割り当てると、`WindowSizing`へ自動登録されます。直接Sceneを作るStageは`WindowSizing.install(stage)`、標準Dialogは`WindowSizing.install(dialog)`を表示前に呼びます。同じStageへ重複登録しても監視は増えません。

制御対象はJavaFX論理座標での装飾込みStage外寸です。表示前はownerの画面、ownerがなければ初期位置の画面を使い、表示後はStageと重なる領域が最大の画面を使います。画面外の位置は最寄りの画面へ補正します。画面ごとのvisualBoundsを使い、OS拡大率を再乗算しません。

表示後の装飾寸法、位置・サイズの変更、画面構成の変更を再評価します。移動・リサイズ中は操作が落ち着いてから補正するため、画面をまたぐドラッグができます。画面より大きい最小サイズはその画面の利用可能サイズへ制限します。大きい画面へ移ったときは、呼出し側が指定した元の最小・最大サイズを再利用します。

最大化・最小化中は位置と通常寸法を補正しません。解除後に再評価し、補正が不要なら位置・寸法・制約のsetterを呼びません。OSによる通常サイズの自動復元自体は保証しません。通常寸法の記録と復元は保存側の責務です。既存の表示・終了イベントは置換しません。

サイズの永続化はこの処理の責務に含めません。復元する通常サイズはshow前にStageへ設定でき、表示時に作業領域へ補正されます。保存側は最大化・最小化中の外寸を通常寸法として記録せず、通常画面から準備画面等へSceneを差し替える前に通常寸法を確定してください。Sceneの変更通知は切替前の寸法を保証しません。

内容の折返しやスクロールは各画面の責務です。Stageが収まることだけで、画面内の全操作へ到達できるとは扱いません。
